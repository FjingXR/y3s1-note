0. What is a static route? Start from zero

A static route is a route that the network administrator types in by hand. The router does not learn it by itself.

Think of it like a hand-written note on your router: "To reach network X, send packets to router Y."

🔁 Dynamic route

Router learns it automatically from a routing protocol (like OSPF).

✍️ Static route

Administrator types it manually. Always the same until you change it.

Static routes are used even when a dynamic routing protocol is running. They give control and backup paths.
✅ Summary: A static route is a manual, permanent "road sign" typed by the admin. It works for both IPv4 and IPv6.

Show answer
The network administrator types it manually (not learned automatically).

Show answer

2. The command syntax How to write the route

IPv4

Router(config)# ip route network-address subnet-mask { ip-address | exit-intf [ip-address] } [distance]

IPv6

Router(config)# ipv6 route ipv6-prefix/prefix-length { ipv6-address | exit-intf [ipv6-address] } [distance]
PartMeaning
network-addressThe destination network you want to reach
subnet-mask / /prefix-lengthHow big is that network
ip-address or exit-intfWhere to send the packet next (you must give one)
distance (optional)Administrative distance — used for floating routes
Before IPv6 routes work, turn routing on: ipv6 unicast-routing
✅ Summary: ip route (IPv4) and ipv6 route (IPv6) are the two commands. You must give at least the destination network + a next hop or exit interface.

3. Next-hop, directly-connected & fully specified

Example network (R1 → R2 → remote networks)

R1(config)# ip route 172.16.1.0 255.255.255.0 172.16.2.2
R1(config)# ip route 192.168.1.0 255.255.255.0 172.16.2.2
R1(config)# ip route 192.168.2.0 255.255.255.0 172.16.2.2

Here only the next-hop IP (172.16.2.2 = R2) is given. R1 finds the exit interface by itself.

IPv6 version

R1(config)# ipv6 route 2001:db8:acad:1::/64 2001:db8:acad:2::2
R1(config)# ipv6 route 2001:db8:cafe:1::/64 2001:db8:acad:2::2
R1(config)# ipv6 route 2001:db8:cafe:2::/64 2001:db8:acad:2::2

Directly connected (interface only)

R1(config)# ip route 172.16.1.0 255.255.255.0 s0/1/0
⚠️ Only for point-to-point serial links. Cisco recommends next-hop instead.

Fully specified (interface + next-hop)

R1(config)# ip route 172.16.1.0 255.255.255.0 s0/1/0 172.16.2.2
For IPv6, a link-local address as next-hop must be fully specified, because link-local addresses are not unique across links — you must name the exit interface too.

4. Default static route The "catch-all" route

A default route matches every packet that has no better match. It is the Gateway of Last Resort.

IPv4 — "quad-zero"

ip route 0.0.0.0 0.0.0.0 172.16.2.2

0.0.0.0 0.0.0.0 = match anything

IPv6

ipv6 route ::/0 2001:db8:acad:2::2

::/0 = match anything

Common use: an edge router connected to the internet, or a stub router (only one upstream neighbour).
MaskMeaning
/0 (IPv4) or ::/0 (IPv6)0 bits must match → matches ALL destinations
more specific route (e.g. /24)router uses it FIRST if it matches
In show ip route, the default route shows an asterisk * = candidate default route.
✅ Summary: Default route = 0.0.0.0 0.0.0.0 (IPv4) or ::/0 (IPv6). It is the last-resort path for unknown destinations.

📝 Quick Check

1. What is the IPv4 default route also called?
Show answer
The "quad-zero" route (0.0.0.0 0.0.0.0).
2. If a packet matches a /24 route AND the default route, which is used?
Show answer
The more specific /24 route is used first.

5. Floating static route Backup path

A floating static route is a backup. It is only used when the main route is gone.

Main routeAD = 1 (default)
→
Backup routeAD = 5 (higher)
→
If main failsbackup becomes active

Administrative Distance (AD) = how trustworthy a route is. Lower AD wins. Static routes default to AD 1.

R1(config)# ip route 0.0.0.0 0.0.0.0 172.16.2.2        ← main (AD 1)
R1(config)# ip route 0.0.0.0 0.0.0.0 10.10.10.2 5      ← backup (AD 5)
R1(config)# ipv6 route ::/0 2001:db8:acad:2::2
R1(config)# ipv6 route ::/0 2001:db8:feed:10::2 5
While the main link is up, the backup (AD 5) does not appear in the routing table. If R2 fails, R1 auto-switches to the backup.
✅ Summary: Floating = same route with a higher AD. The router uses the lowest-AD route. Backup only appears when the main route fails.

📝 Quick Check

1. To make a floating route, do you use a higher or lower AD than the main route?
Show answer
Higher AD (e.g. 5) so it loses to the main route (AD 1).
2. Why is the backup not in the routing table while the main link works?
Show answer
Because the router always chooses the lowest AD; the backup has a higher AD so it is ignored until the main fails.

Smaller routing table, less memory/CPU, faster lookups, fewer updates.

7. Static host route Route to one single device

A host route points to exactly ONE device (one IP), not a whole network.

IP versionMaskMeaning
IPv4/32 (255.255.255.255)one host only
IPv6/128one host only

Example: route to a server

Branch(config)# ip route 209.165.200.238 255.255.255.255 198.51.100.2
Branch(config)# ipv6 route 2001:db8:acad:2::238/128 2001:db8:acad:1::2

Three ways a host route appears

  • Automatic (local): Cisco IOS adds an L route when you configure an interface IP.
  • Static host route: you type it manually (above).
  • Learned: from another method (later courses).
For an IPv6 link-local next-hop, you must use a fully specified route (interface + link-local address).
✅ Summary: Host route = /32 (IPv4) or /128 (IPv6). Used to send traffic to one specific device, e.g. a server.

📝 Quick Check

1. What mask makes an IPv4 route a host route?
Show answer
255.255.255.255 (/32).
2. What does the letter "L" mean in the routing table?
Show answer
A local (host) route automatically added when an interface IP is configured.

8. How a router forwards a packet Module 16 — packet processing

When PC1 sends to PC3, here is what each router does:

1. PC1sends to default gateway (R1)
→
2. R1looks up route → forward to R2
→
3. R2looks up route → forward to R3
→
4. R3ARP → deliver to PC3

Decision logic inside the router

If destination IP…Router action
Matches a static routeUse that route's next-hop / exit interface
No specific match, but default existsUse the default static route
No match at allDROP + send ICMP error back
At the FINAL router (R3), if the destination is on a directly connected Ethernet link, the router uses ARP to find the PC's MAC address, then sends the frame.
✅ Summary: Router matches the destination IP in its table: specific route → default route → else drop + ICMP. Last router uses ARP to reach the host.

📝 Quick Check

1. What happens if a packet matches no route and there is no default route?
Show answer
The router drops it and sends an ICMP message back to the source.
2. At the last router, what protocol finds the destination PC's MAC address?
Show answer
ARP (Address Resolution Protocol).

9. Troubleshoot static & default routes Module 16

Networks fail for many reasons: interface down, ISP drop,饱和 link (overload), or a wrong command typed by the admin.

Your toolbox

CommandUse it to…
pingTest Layer 3 connectivity (extended ping = more options)
tracerouteSee the path / which hop fails
show ip routeView the routing table
show ip interface briefCheck interface status & IP
show cdp neighborsList directly connected Cisco devices (L1/L2 check)

Example problem → fix

Symptom: PC1 cannot ping PC3. R1→R2 and R1→R3 pings work. Problem is on R2's table.
R2# show ip route
S  172.16.3.0 [1/0] via 192.168.1.1   ← WRONG next-hop!
→ remove it, add correct one:
R2(config)# ip route 172.16.3.0 255.255.255.0 172.16.2.1
Method: test step by step (ping local → ping next hop → check each router's table) until you find the broken link.
✅ Summary: Troubleshoot with ping, traceroute, show ip route, show ip interface brief, show cdp neighbors. Find the broken hop, fix or remove the wrong static route.

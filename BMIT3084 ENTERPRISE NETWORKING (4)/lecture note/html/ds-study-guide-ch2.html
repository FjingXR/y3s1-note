0. What is OSPF? Start from zero

OSPF (Open Shortest Path First) is a link-state routing protocol. Unlike older protocols like RIP (distance-vector), OSPF routers know the full network map — not just what their neighbour tells them.

🔁 Distance-Vector (RIP)

Router only knows what its neighbour says. "I heard from Bob that the network is that way."

🗺️ Link-State (OSPF)

Every router has the complete map. Runs Dijkstra's SPF algorithm to find the shortest path.

OSPF was built to replace RIP. It converges faster, scales to bigger networks, and uses cost (not hop count) as the metric.

Single-Area vs Multiarea

🟢 Single-Area

All routers in one area (area 0). Simple. Good for small networks. This is what Chapter 2 covers.

🔵 Multiarea

Network split into many areas, all connected to area 0 (backbone). Smaller routing tables, less CPU work, used in large enterprises.

OSPFv2 = IPv4. OSPFv3 = IPv6 (same basic operation). This chapter covers OSPFv2.
✅ Summary: OSPF = link-state protocol. Every router knows the full topology. Uses cost (bandwidth-based). Single-area = one area. Multiarea = hierarchical.

2. The five OSPF packet types How routers talk to each other

TypePacketPurpose
1HelloDiscover neighbours, build adjacencies, elect DR/BDR
2DBD (Database Description)Check if databases are synchronised (summary of LSDB)
3LSR (Link-State Request)Request specific, more current link-state info
4LSU (Link-State Update)Send the requested link-state records (carries LSAs)
5LSAck (Link-State Acknowledgment)Confirm receipt of LSR or LSU
⚠️ LSU vs LSA: An LSU packet is the envelope that carries LSA messages inside. Think envelope (LSU) and letter (LSA).

Hello packet (Type 1) — the most important

  • Discovers OSPF neighbours and establishes adjacencies
  • Advertises parameters that must match (Hello timer, Dead timer, area ID)
  • Elects DR and BDR on multiaccess networks
  • Sent to multicast address 224.0.0.5 (All OSPF Routers)
✅ Summary: 5 packet types: Hello, DBD, LSR, LSU, LSAck. Hello = neighbour discovery + DR/BDR election. LSU carries LSAs.

4. DR & BDR on multiaccess networks Controlling LSA flooding

On multiaccess networks (like Ethernet with many routers), if every router flooded LSAs to every other, traffic would become chaotic. OSPF elects a Designated Router (DR) to manage LSA distribution.

Three roles

RoleJobMulticast
DR (Designated Router)Collects and distributes all LSAsListens on 224.0.0.6
BDR (Backup DR)Backup if DR fails. Listens passively.Listens on 224.0.0.6
DROTHERNeither DR nor BDR. Sends LSAs only to DR/BDRSends to 224.0.0.6

Election rules

  1. Highest interface priority (0–255) becomes DR. Second highest = BDR.
  2. If priorities are equal, highest Router ID wins.
  3. Priority 0 = cannot be DR or BDR.
  4. Default priority on broadcast interfaces = 1.
  5. Not pre-emptive — adding a new router later does NOT trigger a new election.

If the DR fails

DR fails
→
BDR promotedto DR
→
New BDR electionhighest priority/RID wins

Point-to-point links

On a direct link between two routers, DR/BDR is unnecessary. By default, Cisco Ethernet interfaces use BROADCAST type and elect DR/BDR. Turn this off:

R1(config-if)# ip ospf network point-to-point
✅ Summary: DR manages LSAs. BDR is backup. DROTHERs only talk to DR/BDR (224.0.0.6). Election: priority → RID. Not pre-emptive. Point-to-point = no DR needed.

5. OSPFv2 configuration basics Module 2 — step by step

Step 1: Enable OSPF

R1(config)# router ospf 10

The process-id (1–65535) is locally significant.

Step 2: Set the Router ID

Cisco picks the RID in this order:

  1. Manual: router-id 1.1.1.1 (highest priority)
  2. Highest IP on a loopback interface
  3. Highest IP on a physical interface
R1(config-router)# router-id 1.1.1.1
R1# clear ip ospf process

Step 3: Enable OSPF on interfaces

Method A — network command:

R1(config-router)# network 10.10.1.0 0.0.0.255 area 0
R1(config-router)# network 10.1.1.5 0.0.0.0 area 0
  • Wildcard mask = inverse of subnet mask (e.g. /24 → 0.0.0.255)
  • Quad-zero (0.0.0.0) = match exactly one interface
  • All routers use the same area ID (best: area 0)

Method B — ip ospf on the interface:

R1(config)# interface GigabitEthernet 0/0/0
R1(config-if)# ip ospf 10 area 0

Step 4: Passive interfaces

OSPF sends Hellos out every enabled interface by default. On LANs without OSPF neighbours, this wastes bandwidth.

R1(config-router)# passive-interface GigabitEthernet 0/0/1
The network is still advertised — Hellos just stop being sent out that interface.
⚠️ 3 problems passive interfaces solve: 1) Wasted bandwidth on unnecessary Hellos. 2) All LAN devices process and discard OSPF messages (wasted CPU). 3) Security risk — OSPF packets can be intercepted.
✅ Summary: Enable with router ospf. Set RID with router-id. Enable on interfaces with network or ip ospf. Use passive-interface for LANs with no OSPF neighbours.

6. OSPF cost metric How OSPF chooses the best path

OSPF uses cost as its metric. Lower cost = better path.

The formula

Cost = reference-bandwidth / interface-bandwidth

Default reference bandwidth = 100,000,000 bps (100 Mbps).

InterfaceSpeedDefault cost
Fast Ethernet100 Mbps1
Gigabit Ethernet1,000 Mbps1
10 Gigabit Ethernet10,000 Mbps1
⚠️ Problem: FastEthernet, Gigabit, and 10GE all have cost = 1 (OSPF rounds to integers). OSPF cannot tell which is faster! You must change the reference bandwidth.

Fix: adjust reference bandwidth

R1(config-router)# auto-cost reference-bandwidth 10000
InterfaceCost (ref = 10000)
Fast Ethernet (100 Mbps)100
Gigabit Ethernet (1000 Mbps)10
10 Gigabit Ethernet (10000 Mbps)1
This command must be applied to every router in the OSPF domain. Otherwise, different routers calculate different costs for the same links.

Alternative: manually set cost

R1(config-if)# ip ospf cost 30

Cost accumulates along the path

Total cost = sum of all link costs. Verify with:

R1# show ip route | include 10.10.2.0
O   10.10.2.0/24 [110/11] via 10.1.1.6

[110/11] = AD 110 (OSPF), metric (cost) = 11.

✅ Summary: Cost = ref-bw / interface-bw. Default ref = 100 Mbps — adjust for modern networks with auto-cost reference-bandwidth. Or use ip ospf cost. Total cost = sum of all link costs.

7. OSPF timers Hello and Dead intervals

TimerDefaultMeaning
Hello Interval10 secondsHow often the router sends Hello packets
Dead Interval40 secondsHow long to wait without a Hello before declaring neighbour dead (4 × Hello)
⚠️ Must match! If two neighbours have different Hello or Dead intervals, they will not form an adjacency.

View timers

R1# show ip ospf interface g0/0/0
  Timer intervals configured, Hello 10, Dead 40, Wait 40, Retransmit 5

Change timers

R1(config-if)# ip ospf hello-interval 5
R1(config-if)# ip ospf dead-interval 20
IOS auto-sets Dead = 4 × Hello, but set both explicitly for clarity. Only change timers when you need faster convergence — defaults are best practice for most networks.
✅ Summary: Hello = 10s, Dead = 40s. Must match between neighbours. Change with ip ospf hello-interval and ip ospf dead-interval.

8. Default route propagation Sharing the internet route

A router connecting your OSPF network to the internet (or another non-OSPF network) is called an ASBR (Autonomous System Boundary Router).

Configuration

R2(config)# ip route 0.0.0.0 0.0.0.0 loopback 1
R2(config-router)# default-information originate

Verify on other routers

R1# show ip route | begin Gateway
Gateway of last resort is 10.1.1.6 to network 0.0.0.0
O*E2  0.0.0.0/0 [110/1] via 10.1.1.6, 00:11:08, GigabitEthernet0/0/0
  • O = OSPF
  • * = candidate for default (Gateway of Last Resort)
  • E2 = external route type 2
✅ Summary: ASBR = router between OSPF and non-OSPF. Steps: ip route 0.0.0.0 0.0.0.0 + default-information originate. Other routers see O*E2.

Why neighbours do not form

  • Subnet masks do not match
  • Hello / Dead timers do not match
  • OSPF network types do not match (BROADCAST vs POINT-TO-POINT)
  • Missing or incorrect network command
  • Interface is shut down or has wrong IP
Example neighbour table:

Pri = 0 means point-to-point. FULL = adjacency is working.

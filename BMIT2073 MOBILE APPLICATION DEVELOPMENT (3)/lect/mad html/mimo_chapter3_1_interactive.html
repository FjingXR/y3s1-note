What are widgets? Basic UI building blocks

Q1. What is a widget in Flutter?

Define what a widget is and explain its role in Flutter.

A widget is a UI component of your app. It defines the appearance, layout, and behavior of a specific part of your app's interface. Widgets are nested hierarchically, forming a tree-like structure that defines the overall UI.

Q2. What are the 2 key characteristics of widgets?

Explain why widgets are useful in Flutter development.

  1. Customizable — Most widgets offer various properties you can adjust to customize appearance and behavior, creating unique UIs.
  2. Reusable — Widgets are designed to be reused throughout your app, promoting code efficiency and consistency.

Text Widget Displaying text content

Q4. What is the difference between Text and Text.rich?

Compare the two text widgets and explain when to use each.

TextText.rich
Displays a single run of text with one styleDisplays text with multiple styles using TextSpan children
Simpler, for uniform textMore flexible, for mixed styling (e.g., bold + italic in one line)

Text uses overflow: TextOverflow.ellipsis to truncate long text with "…".

Text.rich uses TextSpan with a children list — each child can have its own TextStyle.

Code example — Text.rich

Text.rich(TextSpan(text: 'Hello', children: [TextSpan(text: ' beautiful ', style: TextStyle(fontStyle: FontStyle.italic)), TextSpan(text: 'world', style: TextStyle(fontWeight: FontWeight.bold))]))

Result: "Hello beautiful world"

TextField Widget User text input

Q5. What are the 3 ways to read a value from TextField?

List and briefly describe each method.

onChanged()

Calls a callback every time the user types. Good for real-time validation or search.

onSubmitted()

Calls a callback when user finishes editing (e.g., presses Enter). Good for form submission.

TextEditingController

Manages text input. Can set initial text, retrieve current text, listen to changes, and clear text.

Q7. What does TextEditingController do?

Explain the 4 capabilities of TextEditingController.

  1. Set initial text — Set default text that appears in the TextField
  2. Retrieve current text — Get the text the user has entered
  3. Listen to text changes — Respond to changes as the user types
  4. Clear the text — Remove all text from the TextField

Always dispose() the controller when the widget is removed to avoid memory leaks.

ElevatedButton & Icon Buttons and icons

Q8. How does ElevatedButton handle enabled/disabled states?

Explain what happens when onPressed is null vs when it has a function.

When onPressed: null → button is disabled (greyed out, not clickable).

When onPressed: () {} → button is enabled (raised, clickable).

Q9. What are IconButton and FloatingActionButton?

Briefly describe these two button variants.

IconButton — An icon-only button, commonly used in AppBar actions.

FloatingActionButton — A circular button that floats above content, used for primary actions (e.g., compose, add).

Q10. How do you use the Icon widget?

Show the properties of the Icon widget.

Properties: Icons class (e.g., Icons.favorite), color, size, semanticLabel (for accessibility).

Example: Icon(Icons.favorite, color: Colors.pink, size: 24.0, semanticLabel: 'Favorite')

Row / Column Arranging widgets

Q12. What is the difference between Row and Column?

How do Row and Column arrange their children?

RowColumn
Arranges children horizontally (left to right)Arranges children vertically (top to bottom)
Uses MainAxisAlignment for horizontal alignmentUses MainAxisAlignment for vertical alignment
Uses CrossAxisAlignment for vertical alignmentUses CrossAxisAlignment for horizontal alignment

Use Expanded to make a child fill available space. Use Flexible to let a child shrink or grow.

Code example — Row with Expanded

Row(children: [Expanded(child: Text('Left')), Expanded(child: Text('Right'))])

Each Expanded takes equal space. Use flex property to control ratio (e.g., flex: 2 = twice the space).

Scaffold & AppBar Material Design structure

Q13. What does Scaffold provide?

Explain the role of Scaffold in a Flutter app.

Scaffold implements the basic Material Design visual layout structure. It provides APIs for showing drawers, snack bars, and bottom sheets.

Typical structure: Scaffold(appBar: AppBar(...), body: Center(...))

Q14. What does AppBar contain?

Describe the AppBar widget and its common properties.

AppBar is a container that displays content and actions at the top of a screen.

Common properties: title (text), actions (list of IconButton), leading (back button).

Single-child Layout One child widgets

Q15. What are single-child layout widgets?

Define single-child layout widgets and list common examples.

These widgets can only hold one child widget. They are used for positioning, sizing, and styling a single element.

Common examples: Align, AspectRatio, Center, ConstrainedBox, Container, Padding, SizedBox.

Q16. What does Container do?

Explain the Container widget and its styling capabilities.

Container groups other widgets and provides styling options like padding, margins, borders, background color, and decoration.

Example: Container(width: 200, height: 100, color: Colors.blue, padding: EdgeInsets.all(20), child: Text('Hello'))

Q17. What does Padding do?

Describe the Padding widget.

Padding insets its child by the given padding value. Commonly used inside Cards or Containers.

Example: Padding(padding: EdgeInsets.all(16.0), child: Text('Hello'))

Q18. What does SizedBox do?

Describe the SizedBox widget.

SizedBox is a box with a specified size. If given a child, it forces the child to have a specific width and height.

Example: SizedBox(width: 200, height: 300, child: Card(child: Text('Hello')))

Multi-child Layout Multiple children widgets

Q19. What are multi-child layout widgets?

Define multi-child layout widgets and list common examples.

These widgets can accommodate multiple child widgets and arrange them in different ways.

Common examples: Row, Column, GridView, ListView, Stack, Wrap.

Q20. What are the 4 key features of multi-child widgets?

Explain layout management, alignment, spacing, and sizing.

  1. Layout Management — Handles arrangement and positioning of child widgets within available space.
  2. Alignment — Control alignment using mainAxisAlignment (Row/Column) or alignment (Stack).
  3. Spacing — Control spacing between children using mainAxisAlignment or spacing property (Flutter 3.27).
  4. Sizing — Control child sizes using mainAxisSize (Row/Column) or flex (Flex).

Q21. What is the difference between GridView and ListView?

Compare these two scrollable widgets.

ListViewGridView
Scrollable list arranged linearly (one direction)Scrollable 2D array (grid of items)
Good for simple listsGood for galleries, dashboards
ListView(children: [...])GridView.count(crossAxisCount: 2, children: [...])

Q22. What does Stack do?

Describe the Stack widget and its use case.

Stack positions its children relative to the edges of its box. Useful for overlapping several children in a simple way.

Children are painted in order — last child is painted on top.

Q23. What does Wrap do?

Describe the Wrap widget.

Wrap displays its children in multiple horizontal or vertical runs. When the available space runs out, it wraps to the next line.

Useful for tag lists, chip rows, or any layout where items should flow naturally.

Sliver Widgets Custom scrolling

Q27. What are sliver widgets?

Define sliver widgets and explain their benefits.

Sliver widgets are building blocks for custom scrolling experiences. They provide a more granular approach than ListView or GridView.

Benefits: Customization (fine-grained control), Performance (efficient for large data), Flexibility (combine different slivers).

Q28. What are the 5 common sliver widgets?

List each sliver widget with its purpose.

WidgetPurposeUse Case
SliverAppBarExpandable/collapsible app barScrolling app bar that hides on scroll
SliverListVertical list with flexibilityLarge lists with variable heights
SliverGridGrid within scrollable areaImage galleries in scroll views
SliverToBoxAdapterEmbed regular widget in scrollAdd a Text or Container in a CustomScrollView
SliverFixedExtentListSame-height list itemsPerformance optimization for uniform lists
ListView vs SliverList

ListView loads ALL records at once. SliverList only loads records visible to the user — much better for large datasets.

Performance Best Practices Optimization tips

Q29. What are the 5 performance best practices?

List all 5 performance tips from the lecture.

1Minimize Widget Rebuilds — Use const for immutable widgets. Avoid costly work in build() methods.
2Optimize Layout — Keep widget tree flat. Avoid unnecessary nesting. Use LayoutBuilder for dynamic layouts.
3Efficient Image Loading — Use Image.network with caching. Resize images. Use WebP format instead of JPEG/PNG/GIF.
4State Management — Call setState only when necessary. Use Provider, Riverpod, or BLoC for complex state.
5Use Built-in Widgets — Flutter's optimized widgets are faster than custom implementations.

Q30. Why is const important for performance?

Explain how using const improves performance.

When you mark a widget as const, Flutter knows its properties won't change. This allows Flutter to skip rebuilding that widget when ancestors rebuild, saving time and memory.

Practice · Extra Questions

Practice Questions Test your knowledge

P1. A developer is building a photo gallery app. Which layout type is best?

Choose single-child or multi-child and justify.

Multi-child (GridView) — A photo gallery needs to display multiple images in a scrollable grid. GridView is designed for this. Single-child widgets can only hold one child.

P2. When would you use Stack instead of Row/Column?

Give a use case for Stack.

Use Stack when you need to overlap widgets — like placing a badge on top of an icon, or a gradient overlay on an image. Row/Column cannot overlap children.

P3. What is the difference between Expanded and Flexible?

Explain when to use each.

Expanded forces the child to fill available space. Flexible lets the child shrink or grow based on its natural size. Use Expanded when you want equal distribution; use Flexible when you want natural sizing with limits.

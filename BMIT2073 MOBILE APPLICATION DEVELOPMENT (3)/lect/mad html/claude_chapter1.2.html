MODULE 1.2

What is Dart?

Lecture 1.2, slide 80–82

Dart is the language you write to build Flutter apps. Before touching widgets, you must know Dart's basic syntax.

Q1. What is Dart and who made it?

Answer

Dart is an open-source, general-purpose programming language made by Google. It is used for:

  • Web development
  • Mobile development (this is what we use it for — Flutter)
  • Server-side development

Q2. What are Dart's key features?

Answer

  • Object-oriented — everything is based on classes and objects
  • Strongly typed — every variable has a fixed data type (helps catch mistakes early)
  • Fast and efficient — compiles to fast native code
  • Modern features — has newer language tools like arrow functions, null safety

Q3. What does a basic Dart program look like?

Answer

Every Dart program starts running from the main() function.

// This is a comment void main() { // This is the main function, program starts here print("Hello, world!"); }
void return type — "void" means this function returns nothing
main() function name — Dart always starts here first, no matter what
print("Hello, world!") a built-in function that shows text on the screen/console
Comments in Dart

Use // text for a single-line comment. Comments are ignored by the program — they are only notes for humans reading the code.

Where to find it

Chapter_1_Merged.pdf — slides 80 to 82 (Introduction, Key features, Structure).

More practice

Which company created Dart?
Google.
What function must every Dart program have to run?
void main() — this is the entry point (starting point) of the program.
What does "strongly typed" mean?
Every variable has a fixed data type (like int or String) that Dart checks — this helps catch mistakes before running the program.

Variables & declaration keywords

Lecture 1.2, slide 84–85, 87

A variable is a named box that stores a value. Dart gives you 3 ways to declare one.

Q1. How do you declare a variable with an explicit (exact) type?

Answer

// Declares an integer variable, needs initialization before use int age; // Declares a double variable double pi = 3.14159; // Declare multiple variables of the same type in a single line int x = 5, y = 10;

Q2. How do you declare a nullable variable?

Answer

Add a ? after the type. This means the variable is allowed to hold null (no value at all).

// Nullable double, initially null double? area = null;

Q3. How does var work?

Answer

var lets Dart guess (infer) the type from the value you assign. Once set, the type cannot change.

// String type with initial value String name = "Alice"; // var infers String based on assignment var greeting = "Hello"; // var infers List<String> based on assignment var flybyObjects = ['Jupiter', 'Saturn', 'Uranus', 'Neptune'];

Explicit type

You write the exact type yourself.

String name = "Alice";
  • Clear and easy to read
  • Good for beginners

var (type inference)

Dart guesses the type from the value.

var greeting = "Hello";
  • Shorter to write
  • Type is fixed after first assignment

Nullable (?)

Variable is allowed to be empty (null).

double? area = null;
  • Add ? right after the type
  • Without ?, null is NOT allowed
Common mistake

int age; (no ?) must get a real value before you use it — Dart will not let it stay empty. Only types with ? can be null.

Where to find it

Chapter_1_Merged.pdf — slides 84, 85, 87 (Variable — Declaration Keywords).

More practice

Write a nullable String variable called "nickname" with no value yet.
String? nickname = null;
What type does Dart infer for var score = 95;?
int — because 95 is a whole number.
Can you assign a String to a variable declared with var after it was first set to an int?
No. Once var infers a type (e.g. int), the variable keeps that type — you cannot later put a String in it.

Control flow — if / for / while

Lecture 1.2, slide 90–92

Control flow decides which code runs, and how many times. Dart has 3 basic structures.

1
if / else if / else — run code only when a condition is true.
2
for loop — repeat code a known number of times, or loop over a list.
3
while loop — repeat code as long as a condition stays true.

Q1. How do you write if / else if in Dart?

Answer

if (year >= 2001) { print('21st century'); } else if (year >= 1901) { print('20th century'); }

Q2. How do you write a for loop? (2 forms)

Answer

Form 1 — count-based for loop:

for (int month = 1; month <= 12; month++) { print(month); }

Form 2 — for-in loop (loop over each item in a list):

for (final object in flybyObjects) { print(object); }

Q3. How do you write a while loop?

Answer

while (year < 2016) { year += 1; }
for vs while — when to use which?

Use for when you know how many times to repeat (e.g. "12 months", "every item in a list"). Use while when you don't know the exact count — it just keeps going until the condition becomes false.

Where to find it

Chapter_1_Merged.pdf — slides 90 (if/else if), 91 (for, for-in), 92 (while) — "Basic Structures".

More practice

Write a for-in loop that prints every item in a list called "fruits".
for (final fruit in fruits) { print(fruit); }
What is the difference between a for loop and a while loop?
A for loop is best when you know the number of repeats in advance. A while loop repeats as long as a condition is true — you may not know the exact count ahead of time.
What keyword starts an "otherwise, if this is true" branch in Dart?
else if.

Functions

Lecture 1.2, slide 93–95

A function is a named block of code that can take inputs (parameters) and give back an output (return value).

Q1. What are the parts of a Dart function?

Answer

bool isNoble(int atomicNumber) { return _nobleGases[atomicNumber] != null; }
bool return type — this function gives back a true/false value
isNoble function name — describes what the function does
(int atomicNumber) parameter — the input the function needs to do its job
return ...; function body — the code that runs, ending with the return statement

Q2. What is recursion? Show an example.

Answer

Recursion = a function that calls itself to solve a smaller version of the same problem.

int fibonacci(int n) { if (n == 0 || n == 1) return n; return fibonacci(n - 1) + fibonacci(n - 2); } var result = fibonacci(20);
How the fibonacci example works

If n is 0 or 1, just return n (this is the "stop" condition — called the base case). Otherwise, the function calls itself twice with smaller numbers, and adds the results.

Q3. What is arrow syntax (=>)?

Answer

Arrow syntax is a shortcut for a function body that is just one expression. It replaces { return ...; } with => ...;

bool isNoble(int atomicNumber) => _nobleGases[atomicNumber] != null;
Block function (return)Arrow function (=>)
Syntax{ return value; }=> value;
Best forMultiple lines / multiple stepsOne single expression only
Example
bool isNoble(int n) { return _nobleGases[n] != null; }
bool isNoble(int n) => _nobleGases[n] != null;

Q4. What are higher-order functions? (.where, .forEach)

Answer

A higher-order function takes another function as an input (often written as a short lambda / anonymous function using =>).

flybyObjects.where((name) => name.contains('turn')).forEach(print);
  • .where(...) — keeps only items that match a condition
  • .forEach(...) — runs a function on every item in the list
  • (name) => name.contains('turn') — an anonymous function (lambda) with no name, used only once
Reading the example above

flybyObjects.where((name) => name.contains('turn')) keeps only names containing "turn" (like "Saturn"), then .forEach(print) prints each matching name.

Where to find it

Chapter_1_Merged.pdf — slides 93 (function basics), 94 (recursion), 95 (arrow syntax, higher-order functions).

More practice

Convert this to arrow syntax: int square(int n) { return n * n; }
int square(int n) => n * n;
In the fibonacci function, what is the base case?
if (n == 0 || n == 1) return n; — this stops the recursion from calling itself forever.
What does .forEach(print) do to a list?
It runs print() on every single item in the list, one by one.

One-paragraph recap

  • Dart is Google's language for Flutter — object-oriented, strongly typed, fast.
  • Every program starts at void main(); print() outputs text.
  • 3 data type groups: Numbers (int, double, num), Text (String), Logical (bool).
  • 3 ways to declare variables: explicit type, var (inferred), nullable with ?.
  • Control flow: if/else if/else for decisions, for/for-in for known repeats, while for condition-based repeats.
  • Functions have a return type, name, parameters, and a body — can use => for one-line bodies.
  • Recursion = function calling itself, needs a base case to stop.
  • Higher-order functions like .where() and .forEach() take another function as input.

Common mistakes to avoid

  • Forgetting that a non-nullable variable (no ?) must be given a value before use.
  • Mixing up var (type inferred once, then fixed) with dynamic typing (Dart is NOT dynamically typed by default).
  • Forgetting the base case in a recursive function — this causes infinite recursion (crash).
  • Using => arrow syntax for a function body with multiple statements — arrow only works for ONE expression.
  • Confusing for (known repeat count) with while (condition-based, unknown count).

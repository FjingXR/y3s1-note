Chapter 1.2 — Dart Programming Basics

This page covers Dart's core concepts: variables, data types, control flow (if/for/while), and functions. All explanations are theory-first — focused on what each feature is and how it flows, not memorising syntax.

MODULE 1.2

What is Dart?

Lecture 1.2, slide 80–82

Dart is the language you write to build Flutter apps. Before touching widgets, you must understand Dart's basic building blocks.

Q1. What is Dart and who made it?

Answer

Dart is an open-source, general-purpose programming language created by Google. It is used for:

  • Web development
  • Mobile development (this is what we use it for — Flutter)
  • Server-side development

Q2. What are Dart's key features?

Answer

  • Object-oriented — everything is built around classes and objects
  • Strongly typed — every variable has a fixed data type (catches mistakes early)
  • Fast and efficient — compiles to native machine code
  • Modern features — null safety, arrow functions, higher-order functions

Q3. What is the structure of a Dart program?

Answer

Every Dart program has an entry point — a special function where execution begins. The three key structural elements are:

Return type
Declares what the function gives back. void means it returns nothing at all.
Entry point
The function named main — Dart always starts here first, no matter what else is in the file.
Output
The built-in print() function displays text to the console. Everything inside the parentheses is shown on screen.

Comments — use // for single-line notes. Comments are ignored by the program; they exist only for humans.

One program, one entry

Every Dart file can have only one main() function. Think of it as the front door — the program walks in through main() and follows the instructions from there.

Which company created Dart?
Google.

Variables & declaration keywords

Lecture 1.2, slide 84–85, 87

A variable is a named storage box that holds a value. Dart gives you three ways to declare one, each with different rules about type flexibility and nullability.

Q1. What are the three declaration keywords and how do they differ?

Answer

Explicit type
You write the exact type yourself (e.g. int, String). The variable must be given a value before it is used. It cannot be null unless you add ?.
var
Dart infers (guesses) the type from the value you assign. Once set, the type is fixed — you cannot later store a different type. Shorter to write, but the same strictness as explicit typing.
Nullable ?
Add ? after any type (e.g. int?, String?). This allows the variable to hold null (no value at all). Without ?, the variable can never be null.

Q2. What happens if you use an uninitialised non-nullable variable?

Answer

Dart will refuse to compile — it catches the error before the program ever runs. A non-nullable variable (no ?) must always have a concrete value assigned before you read it. This is Dart's null safety feature working to prevent crashes.

Explicit type

You write the exact type yourself. Clear and readable, good for beginners.

  • Pros: very clear intent
  • Cons: more to type
  • Null? Only if you add ?

var (type inference)

Dart guesses the type from the initial value. Shorter, but just as strict.

  • Pros: less typing
  • Cons: type is hidden
  • Null? Depends on initial value

Nullable ?

The variable is allowed to be empty. Adds ? right after the type name.

  • Pros: prevents null crashes
  • Cons: must handle null checks
  • Null? Yes, explicitly allowed
Common mistake

Declaring int age; without ? and without a value — Dart will not compile this until you assign a value. Only types marked with ? can hold null.

More practice

How do you declare a variable that is allowed to hold no value at all?
Add ? after the type — e.g. String? nickname. This makes it nullable, meaning it can hold null.
What type does Dart infer for var score = 95;?
int — because 95 is a whole number, so Dart infers the type as int.
Can you assign a String to a variable declared with var after it was first set to an int?
No. Once var infers a type (e.g. int), the variable keeps that type permanently — you cannot later put a String in it.

Data types

Lecture 1.2, slide 83, 86, 88–89

Dart groups its basic data types into three categories: Numbers, Text, and Logical (Boolean). Every value in Dart belongs to exactly one type.

Q1. What are Dart's basic data types?

Answer

TypeCategoryMeaning
intNumbersStores whole numbers (integers) — e.g. 20, -3, 0
doubleNumbersStores numbers with decimals (floating-point) — e.g. 3.14159, -0.5
numNumbersSupertype of both int and double — can hold either kind
StringTextStores a sequence of characters (text) — e.g. "Hello", "Alice"
boolLogicalStores true or false only — the Boolean type

Q2. What is the difference between num, int, and double?

Answer

  • num is the parent type — it can hold either an int or a double
  • int is for whole numbers only (no decimal point)
  • double is for decimal numbers (has a fractional part)

Use num only when a value might genuinely be either type; otherwise be exact with int or double.

Q3. What values can a bool hold?

Answer

Exactly two values: true or false. There is no third option. Booleans are used in conditions — e.g. deciding whether to run an if block.

Everything is an object

In Dart, even basic values like int and bool are objects — they have methods and properties you can call. This is different from languages like Java where primitives are not objects.

Control flow — if / for / while

Lecture 1.2, slide 90–92

Control flow decides which code runs and how many times. Dart has three basic structures.

1
if / else if / else — run a block only when a condition is true. Optionally check additional conditions with else if, and catch everything else with else.
2
for loop — repeat a block a known number of times. Two forms: count-based (run N times with a counter) and for-in (loop over every item in a collection).
3
while loop — repeat a block as long as a condition stays true. The condition is checked before each iteration; if it is false initially, the body never runs.

Q1. How does the if / else if flow work?

Answer

Dart checks conditions top to bottom. The first condition that evaluates to true runs its block, and everything after is skipped. If no condition is true, the else block runs (if provided).

  • if (condition) — runs if condition is true
  • else if (condition) — runs if previous if was false AND this condition is true
  • else — runs if nothing above was true (catch-all)

Q2. What is the difference between a count-based for loop and a for-in loop?

Answer

  • Count-based for: uses a counter variable, a condition, and an increment. Runs exactly as many times as the condition allows (e.g. "12 times for 12 months").
  • For-in: iterates over every element in a collection (like a list). You don't manage a counter — Dart gives you each element one at a time.

Q3. When should you use a while loop instead of a for loop?

Answer

Use while when you don't know the exact number of repetitions ahead of time — the loop keeps going until the condition becomes false. Use for when you know the count in advance (e.g. "iterate over 10 items").

For vs while — quick rule

For = "I know how many times" (e.g. 12 months, every student in a list). While = "I don't know how many times — just keep going until something changes."

More practice

What loop structure would you use to print every item in a list called "fruits"?
A for-in loop. It iterates over each element in the collection without needing a manual counter.
What is the difference between a for loop and a while loop?
A for loop is best when you know the number of repeats in advance. A while loop repeats as long as a condition is true — you may not know the exact count ahead of time.
What keyword starts an "otherwise, if this is true" branch in Dart?
else if.

Functions

Lecture 1.2, slide 93–95

A function is a named block of code that can take inputs (parameters) and give back an output (return value). Functions let you package logic so you can reuse it without rewriting.

Q1. What are the parts of a Dart function?

Answer

Every function has four parts that appear in this order:

Return type
What the function gives back (e.g. int, bool, String). Use void if it returns nothing.
Function name
A descriptive name (e.g. isNoble, calculateArea) that says what the function does.
Parameters
Inputs the function needs to work — written in parentheses after the name. Each parameter has a type and a name.
Body
The block of code that runs inside { }. The return statement sends a value back to the caller.

Q2. What is recursion?

Answer

Recursion = a function that calls itself. It solves a problem by breaking it into smaller versions of the same problem. Every recursive function needs a base case — a condition that stops the recursion (otherwise it calls itself forever and crashes).

Example flow — the fibonacci sequence:

  • If n is 0 or 1, just return n (this is the base case)
  • Otherwise, call the function twice with n-1 and n-2, then add the two results together

Q3. What is arrow syntax (=>) and when do you use it?

Answer

Arrow syntax (=>) is a shorthand for a function body that contains only one expression. It replaces { return ...; } with => ...; — removing the curly braces and the return keyword.

  • Block body: { return value; } — use when you need multiple lines or steps
  • Arrow body: => value; — use when the logic is a single expression

Q4. What are higher-order functions?

Answer

A higher-order function is a function that takes another function as an input (often written as a short lambda/anonymous function). Common examples on collections:

  • .where(predicate) — filters a collection, keeping only items that match a condition
  • .forEach(action) — runs a function on every item in the collection
  • Lambda — an anonymous (unnamed) function written inline, often using =>
Reading higher-order chains

You read them left to right: "take the collection → keep only items matching a condition → do something with each remaining item."

Arrow = one expression only

The arrow => only works when the function body is a single expression. If you need multiple statements (e.g. a loop, multiple variables), use the block body { } with a return.

More practice

What is the shorthand syntax for a function that contains only one expression?
Arrow syntax (=>). It replaces { return ...; } with => ...;
In a recursive function, what must you include to prevent infinite calls?
A base case — a condition that stops the recursion (e.g. if (n == 0) return n;). Without it, the function calls itself forever and crashes.
What does .forEach() do to a list?
It runs a given function on every single item in the list, one by one.

One-paragraph recap

  • Dart is Google's language for Flutter — object-oriented, strongly typed, fast, with null safety built in.
  • Every program starts at main(); print() outputs text to the console.
  • 3 data type groups: Numbers (int, double, num), Text (String), Logical (bool).
  • 3 ways to declare variables: explicit type, var (type inferred), nullable with ?.
  • Control flow: if/else if/else for decisions, for/for-in for known repeats, while for condition-based repeats.
  • Functions = return type + name + parameters + body. Use => arrow for one-expression bodies.
  • Recursion = function calling itself; always needs a base case to stop.
  • Higher-order functions like .where() and .forEach() take another function as input to process collections.

Common mistakes to avoid

  • Forgetting that a non-nullable variable (no ?) must be given a value before use — Dart will not compile otherwise.
  • Mixing up var (type inferred once, then fixed) with dynamic typing — Dart is NOT dynamically typed by default.
  • Forgetting the base case in a recursive function — this causes infinite recursion (stack overflow crash).
  • Using => arrow syntax for a function body with multiple statements — arrow only works for ONE expression.
  • Confusing for (known repeat count) with while (condition-based, unknown count).

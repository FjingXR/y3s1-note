About this subject ▶

BMIS2113 — Information Technology Infrastructure (ITI) is a third-year semester subject that covers the core building blocks of modern IT infrastructure — from datacentres and networking to compute, storage, and security.

You will learn how physical and virtual infrastructure is designed, managed, and secured: how data centres are built, how networks carry traffic, how storage systems (RAID, SAN, NAS, object storage) work, how compute resources are virtualized, and how non-functional attributes like availability, performance, and security shape infrastructure decisions.

Across the 6 chapters you'll move from foundational concepts — datacentre tiers, network topologies, RAID levels — through to advanced topics like software-defined storage and virtualization. The midterm covers Chapters 1 through 5.

Chapter 2 — Non-functional Attributes
module 2DeepSeek

Non-functional Attributes

Availability, reliability, maintainability, serviceability, scalability, security, performance, cost, capacity planning, SLA/SLO/SLI trade-offs.

C2
▶ mini cheatsheet
  • Availability = uptime (e.g. 99.9% = ~8.7 hrs downtime/year).
  • Scalability = ability to grow capacity when needed (vertical vs horizontal).
  • Security = CIA triad: Confidentiality, Integrity, Availability.
  • SLA = Service Level Agreement (contract). SLO = target. SLI = actual measurement.

Chapter 3 — Datacentres
module 3DeepSeek

Datacentres

Datacentre tiers (I–IV), power & cooling, rack layout, cabling, physical security, fire suppression, redundancy (N, N+1, 2N).

C3
▶ mini cheatsheet
  • Tier I = no redundancy (99.671% uptime).
  • Tier II = redundant components (99.741%).
  • Tier III = concurrent maintenance (99.982%).
  • Tier IV = fault tolerant (99.995%).
  • N = needed capacity. N+1 = one spare. 2N = full duplicate.

Networking

C4
▶ mini cheatsheet
  • OSI 7 layers: Physical → Data Link → Network → Transport → Session → Presentation → Application.
  • TCP/IP 4 layers: Link → Internet → Transport → Application.
  • VLAN = virtual network segment. SDN = control plane separated from data plane.

Chapter 5 — Storage
module 5DeepSeek

Storage

Storage building blocks, HDD vs SSD vs Tape, RAID levels (0/1/10/5/6), controllers, DAS vs SAN vs NAS, object storage, SDS, backup & recovery, replication, storage tiering, security.

C5
▶ mini cheatsheet
  • RAID: 0=stripe, 1=mirror, 10=both, 5=parity, 6=double parity.
  • DAS = direct to server. SAN = block-level network (FC/iSCSI). NAS = file-level (SMB/NFS).
  • Replication: sync (0ms, ≤100km) vs async (has lag, no distance limit).
  • 3-2-1 backup: 3 copies, 2 media, 1 offsite.
  • GFS retention: Grandfather (monthly) → Father (weekly) → Son (daily).
  • SDS = software-defined storage, abstracts control plane from data plane.

Chapter 6 — Compute
module 6DeepSeek

Compute

Server types, CPU architecture, virtualization (Type 1/2 hypervisors), containers vs VMs, cloud compute (IaaS/PaaS/SaaS), load balancing, cluster computing.

C6
▶ mini cheatsheet
  • Type 1 hypervisor = bare metal (VMware ESXi, Hyper-V). Type 2 = runs on OS (VirtualBox).
  • Virtualization = one physical server runs multiple VMs with isolated OS instances.
  • Containers = share host OS kernel, lighter than VMs (Docker).
  • IaaS = raw compute. PaaS = platform. SaaS = software ready to use.

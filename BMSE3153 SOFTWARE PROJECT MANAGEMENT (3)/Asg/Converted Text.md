**A Mobile Application for Public Transportation Information and Journey Planning in Malaysia**

**Problem:**

Public transport information is scattered across multiple sources, making it difficult for commuters to plan efficient journeys.

**Solution:**

A single mobile application that centralizes transport information and makes it searchable and map-based.

**Dataset website**

<https://data.gov.my/>
